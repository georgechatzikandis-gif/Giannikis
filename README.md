# Giannikis — Sign & Print

Animated one-page website for Giannikis (Επιγραφές – Εκτυπώσεις), Κρεμαστή, Ρόδος.

Plain HTML/CSS/JS — no build step. Open `index.html` in a browser, or upload the folder to any static host (GitHub Pages, Netlify, cPanel…).

```
index.html        page (Greek, with EL/EN toggle)
css/style.css     styles & animations
js/main.js        scroll reveals, parallax, counters, lightbox, language toggle, quote form
assets/img/       logo (PNG with transparency) + optimised showroom photos
assets/video/     building & pylon clips (H.264 MP4, muted)
IMG_81xx.jpeg     original full-size photos
```

The quote form opens the visitor's email app with a pre-filled message to info@giannikis.eu.
